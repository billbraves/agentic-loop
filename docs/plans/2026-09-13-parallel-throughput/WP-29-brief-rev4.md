## 本 rev 的验收标的

### 标的 0 —— 可机械检查的取证判据（贯穿全部四条，阻断项）

> **判据**：§1 里每一个形如 `$ <命令>` 的命令块，按**字面原文**重跑，其输出行数
> **必须等于**紧随其后粘贴的输出块行数。

三条推论，逐条遵守：

1. **凡用了过滤器，就必须写进命令原文。** 包括 `--exclude`、`--exclude-dir`、
   管道后的 `grep -v`、`head`、`sort -u`、`| wc -l` 之外的任何裁剪。
   不得在正文里用「（已排除交付物自身）」这类括注代替 —— 括注不进命令原文，
   重跑的人拿不到同样的结果。
2. **凡粘贴输出，就必须逐字完整。** 不得出现 `……`、`（略）`、`（同前）`、
   `（另匹配 N 处）`、`...`（三点省略）等任何形式的省略或摘要计数。
   长行（例如 JSON 单行）也必须整行粘贴，哪怕它横向很长。
3. **凡声明了行数/条数，就必须与粘贴块的实际行数相等。** 交付物里若写「共 N 行」，
   N 必须能由粘贴块数出来。

编排者验收时会对 §1 的每个命令块执行这条判据（逐字重跑 + `wc -l` 比对），
**任何一处不等即 REWORK**。这是 rev3 判 REWORK 的直接原因，也是本 rev 的核心。
