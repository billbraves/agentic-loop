## 2. 三轮是不是同一个根因

是，但根因**不是**「面还不够多」。这是本次复核最重要的更正。

三轮的攻防账面：

- rev1：六个面 → 我按组成步骤重造变异，露出 3 个面（围栏渲染 / 块内去规范化句 / 数量词）
- rev2：九个面 → 我按组成步骤重造变异，又露出 2 个面（HTML 注释包裹 / 未列入黑名单的同义句）
- 若照此续补，rev3 会露出第 3 批（其他 raw HTML block、不同长度围栏、`<pre>`/`<script>`、
  缩进 code、更远处的矛盾条款……），且**每一批都能在事后被解释为「本可想到」**。

真正的根因是**量词超出了判据模型的表达力**：

> brief 声称覆盖「**任何**削弱其规范力的模板改动」。「规范力」是开放世界的自然语言语义性质，
> 没有形式化定义。而攻击面清单本身就是一次枚举 —— 枚举只能证明**有界的存在/排除命题**，
> 永远证不出 brief 写下的那个全称命题。

这一点由 codex 独立确认并被我实测复现（详见 §4）。关键的区分是：

- **「块体与冻结常量逐字节相等」是封闭模型** —— 它覆盖块体的每一个字节位置，
  不是按已知缺陷形状枚举，所以有限判据在此是**完整**的。这类判据可以承载全称命题。
- **「不得包含以下去规范化短语」是黑名单** —— 它只覆盖列进去的那些表示。
  这类判据无论补到多长，都只能承载「已识别的削弱表示被排除」。

rev1/rev2 的九个面里，S1/S6 属前者（唯一性覆盖全部标题行），S2/S3/S5b/S7 属后者。
**判据的整体强度由最弱的那一侧决定**，所以补黑名单不改变收敛性。

## 3. 我的计划面失误（这是本次复核的实质产出）

### 失误 1：把开放世界的语义性质当成可枚举的攻击面清单来冻结

INV-N 的原文写的是「无论通过删正文、改极性、改结构、改定位、还是改处境」，
后面跟一句「若你发现本 brief 未枚举的第六类逃逸……一并钉住」。
这个写法同时做了两件互相矛盾的事：**用列举定义外延**，又**要求覆盖列举之外**。
执行者照列举做就够不着不变式；我按组成步骤造变异就必然还能找到列举外的形状。
这不是执行者的能力问题，也不是我变异造得不够狠 —— 是**规格本身不可兑现**。

正确做法是把承诺拆成几条**各自封闭**的硬变式，并对做不到的部分**明文声明不覆盖**，
而不是写一条全称命题再靠补面去逼近它。

### 失误 2：把「归一化后相等」当成「冻结」

rev1 因跨行极性常量造成纯折行假阳性，我在 rev2 的修法是引入 `_normalize_ws()`
（`" ".join(text.split())`）。这个等价关系比我当时以为的宽得多：Markdown 里空白是**语义**的
（行首四空格 → code block；空行结束 list；行尾两空格 → hard break）。
所以「归一化后相等」不能承载「文本已冻结」的说法。

我在复核中曾把这条记为新缺陷 B46，随后实测发现 S4 的独立缩进检查会把该例子红掉，
于是撤回了「live escape」的定性。**但撤回的只是「有一条现成逃逸」，不是这条设计判断** ——
等价关系承载不了赋予它的重量，这一点成立，且是 rev3 必须改掉的（改用真逐字节相等）。

### 失误 3：让检查顺序承担归因责任

rev2 的判据用「九个检查按固定顺序跑，取 `violations[0]` 作为归因」。
这导致我在 rev1 复核时踩过一次坑（诱饵块把 S5 的前一行顶掉，红的归因落错面），
rev2 靠「S6 必须先于 S5」的顺序约定补上。顺序约定是脆的：新增一个面就要重排一次，
且顺序既决定归因、又参与放行判定，两个职责耦合在一起。

正确做法（codex §3，我采纳）：硬不变式**各自独立运行**，任一失败即红；
块体不等之后**再**对 diff 做二次归因分类；分类漏掉某种形状时由通用 `BODY_MISMATCH` 兜底 ——
**细化面不再是放行依据**。witness 返回结构化 code，不依赖列表下标。

### 失误 4（次要，纯记账）：rev2 brief 自身的数目不一致

rev2 §A 表格有 9 行（S1/S2/S3/S4/S5/S6/S4b/S5b/S7），而 §B 与 DoD 的散文写「八个面」。
这是我在冻结时的漏数，不是执行者的问题；执行者按 9 行表格实现是对的。rev3 不再沿用面编号，
该不一致随之消失。

## 4. 实测确证（编排者本轮独立复现，不采信任何一方转述）

### 4.1 逃逸的真实边界（B44 族）

codex 断言「块体等值只证明 substring，证不出它在完整文档中的解释」。我实测确证，
并且**修正了我自己在复核中的一处粗糙表述**：并非任何 HTML 注释包裹都能逃逸 ——
若闭合标记 `-->` 落在块体切分范围内，块体字节就变了，判据会红（这是**偶然**红，不是覆盖）。
保持两块 body 逐字节完好的变体是**把开启标记放到块外**：

| 变体 | 两块 body 逐字节未变 | 收缩后判据 |
|------|------------------|-----------|
| 整份文档外包 `<!-- … -->` | 是 | **GREEN（逃逸）** |
| 文档开头留未闭合 `<!--` | 是 | **GREEN（逃逸）** |
| 在 `## 附注` 内开一个未闭合代码围栏 | 是 | **GREEN（逃逸）** |

结论：`active_embedding`（块是否作为活动文本渲染）**必然**是至少部分依赖块外上下文的性质，
块内字节相等在原理上无法覆盖它。所以它不能靠「再加一个 HTML 注释深度计数器」收口 ——
那只是又一个不完整的 Markdown mini-parser。

### 4.2 远距离去规范化（B45 族）

在文档**最开头**加一句「下列所有流程规则均已废止，仅供历史参考。」→ 收缩后判据 **GREEN**。
自然语言的规范力没有有限的上下文半径，这句可以离冻结块任意远。
rev2 的 S5（守紧邻前一非空行）与 S5b（守块内短语黑名单）都不可能覆盖它。

### 4.3 收缩后判据的正向可达与强度（原型 `narrow.py` + `probe5b.py`）

- **正向对照**：未变异的真实模板（worktree `b34deb9`）→ `POSITIVE CONTROL: GREEN`
- **变异集按【收缩后判据】的 7 个组成步骤生成**（T1 逐行标题计数 / T2 NFKC 同形 /
  T3 块体字节切分 / T4 块体逐字节相等 / T5 诊断分类兜底 / T6 位置锚点 / T7 副本同一），
  **共 17 条，全红，0 逃逸，归因逐步骤正确**（`MISATTRIBUTED: none`）
- **无害探针 4 条全绿**（改无关占位符 / 文末追加新章节 / 改 `## 范围` 正文 / 改抬头冻结日期行）
- 其中两条专门验证兜底：块内追加散文、块内列表项重排（字节集合不变、顺序变）——
  两条都命中 `BODY_MISMATCH` 而**任何诊断分类都没识别出来**，证明兜底真的在承重。

**实测中我自己的原型暴露的两个缺陷（记此一笔，正是按组成步骤生成的价值）**：

1. **变异空操作导致假绿**：首版「纯折行」变异按 `rfind('，', 0, 40)` 找折点，
   H2 块内没有满足条件的行 → 变异其实是恒等映射，报告成 GREEN 逃逸。
   这与我在 rev2 复核时那次 `NFD` 空操作**同型**。改法：变异函数一律带
   `assert d != DOC` 前置断言，空操作直接报「变异自身缺陷」而不是「判据放行」。
   **这一条应写进 rev3 的 DoD**，因为它是假绿的通用来源。
2. **副本检查混淆逐条归因**：首版只变异 doc 一侧却同时比对 tmpl，
   于是 `REPLICA_MISMATCH` 出现在**每一条**变异的 witness 里，
   任何步骤的红都无法与副本同一区分开。改法：T1–T6 的变异同步施加到两份，
   使 T7 成为唯一考察副本同一的步骤。

### 4.4 支撑「拆包」而非「本 WP 内解决」的三项事实

均由我独立核实：

1. `_normalize_ws()` 确实是 `" ".join(text.split())`，即无条件折叠全部空白。
2. 全仓**没有**任何 Markdown parser 依赖，也没有任何文档声明权威 Markdown 方言。
3. `WORK_PACKAGE.md.tmpl` 在仓内的**唯一**消费者是 `init_cmd.py:109`
   （`_REFERENCE_TEMPLATES`），它**逐字节复制**该文件，不解析其 markdown。

第 2、3 条合起来说明：要兑现 `active_embedding`，必须先决定权威方言、引入 parser 依赖、
定义目标 AST 与消费链 —— 这四件事都**超出 WP-28 已冻结的 3 个 `allowed_paths`**，
必须另立工作包。

## 5. rev3 的范围裁定（本次复核的决定，用户已批准方向）

**裁定：WP-28 收缩为两条各自封闭的硬不变式，并对做不到的部分明文声明不覆盖。**

rev3 的验收标的：

> **INV-N1（受保护块身份）**：在两份 WP 模板中，`## Re-freeze 规则（编排者冻结前自检）`
> 与 `## Acceptance tests` 各恰好存在一次（逐行精确匹配；NFKC 同形副本按「边界不唯一」判红）；
> 每块的**完整 body 与测试中的冻结常量逐字节相同**；每块的前后 `## ` 兄弟锚点与冻结值相同。
> 任何受保护字节的新增、删除、替换或重排，若不同时修改冻结常量，测试必须转红。

> **INV-N3（副本同一）**：`docs/agentic/templates/WORK_PACKAGE.md` 与
> `src/agentic_loop/templates/WORK_PACKAGE.md.tmpl` 逐字节相同。

> **INV-N4（变更可见性）**：改变上述受保护字节或锚点，必须在测试的冻结常量里留下可审查 diff。
> 测试只负责强迫变更**可见**，不负责判断该变更**是否获批**。

**明文声明不覆盖**（写入 rev3 brief 正文，不是脚注）：

> 本判据只保证冻结块的 **raw text 身份、唯一性与声明的位置锚点**不变。
> 它**不**保证：块外编辑不改变其 Markdown 渲染上下文（§4.1 三条实测逃逸）；
> 文档远处不存在去规范化或矛盾条款（§4.2 实测逃逸）；任意渲染器把它显示为活动文本；
> 实际消费者一定采纳这份模板；所有「语义等价的削弱」都会被识别。
> **规范力本身不是本 WP 的验收标的。**

配套的判据形状要求：

1. **硬不变式独立运行**，任一失败即红；不靠检查顺序决定放行。
2. **S2/S3/S4/S7 降级为诊断分类**，只在块体不等之后对 diff 做二次归因；
   分类不出时由 `BODY_MISMATCH` 兜底 —— 分类缺失**不得**成为放行依据。
3. **用真逐字节相等**，不用 `_normalize_ws()`。折行也算受保护字节变化，须同步改冻结常量
   （冻结文字本就不需要支持随意格式化）。
4. **witness 返回结构化 code**（`SECTION_NOT_UNIQUE` / `BODY_MISMATCH` /
   `SECTION_ANCHOR_MOVED` / `REPLICA_MISMATCH` 等），不依赖 `violations[0]` 的执行顺序。
5. **变异函数须带 `assert 变异后 != 变异前`**（§4.3 缺陷 1），空操作报为变异缺陷而非判据放行。
6. **变异同步施加到两份模板**，使副本同一成为独立考察的步骤（§4.3 缺陷 2）。

明确**不**纳入 rev3（避免范围膨胀成第 4 次返工）：

- **B44 族（渲染/活动嵌入）** —— 另立 **WP-29**。该 WP 必须先定义权威 Markdown 方言、
  parser 版本与依赖、目标 AST 与消费链，然后才谈判据。**不得**在 WP-28 内继续加
  HTML 注释深度计数器或围栏状态机 —— 那是伪收口（§4.1）。
- **B45 族（远距离自然语言去规范化）** —— 归入同一个 WP-29 的范围界定阶段一并裁定；
  若结论是「机械不可兑现」，则应作为**已知限制**写入模板而不是继续造判据。
- rev2 已通过的面不回退：B43（`re.finditer` 取代 `text.index()`）保留；
  两份模板逐字节同一保留；现有 7 条既有用例只增不减。

## 6. 应固化为常规的流程改动（超出本 WP）

1. **不变式必须是封闭模型，不能是攻击面枚举。** 冻结前自问：这条判据是覆盖了输入空间的
   某个**完整维度**（如全部字节位置、全部标题行），还是只覆盖了**我想到的那些表示**？
   后者只能写成有界命题。建议落到 AGENTS.md 的冻结协议，另立任务。
2. **变异函数必须自证非空操作。** 我在两轮复核里各踩一次（NFD 空操作、折行空操作），
   两次都短暂得出错误结论。建议写入模板的 oracle 条目：变异须断言「变异后 ≠ 变异前」。
3. **做不到的部分要明文声明不覆盖。** 一条诚实的降级声明比一条不可兑现的全称命题更有价值 ——
   后者会持续消耗返工预算，且给人「已被守住」的错觉。
